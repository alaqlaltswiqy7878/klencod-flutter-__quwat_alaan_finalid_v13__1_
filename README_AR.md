# قوة الآن 💪 — V13

## ما أُضيف في هذه الدورة

### خريطة الـ24 ساعة
- زر «خريطة يومي» في أعلى الصفحة الرئيسية، ولا تُفتح تلقائياً.
- ملخص للوقت المشغول، الوقت المتاح، عدد المهام ونسبة جدولة اليوم.
- عرض زمني مرتب لمهام اليوم من 00:00 إلى 24:00، مع التصنيف وحالة الإنجاز.

### منع التداخل
- منع كامل لأي تداخل زمني بين مهمتين، عند الإضافة أو التعديل أو الإنشاء من المساعد.
- إذا كانت المهمة من 08:00 إلى 08:30، تُرفض مهمة تبدأ 08:20، وتُقبل مهمة تبدأ 08:30.
- التكرار اليومي والأسبوعي يفحص الأيام المشتركة خلال دورة سنوية، مع استثناء المهمة نفسها عند التعديل.
- المهمة الفرعية لا تُعامل كمهمة زمنية مستقلة.

### السجل اليومي
- زر «السجل اليومي» يفتح سجلاً مستقلاً لكل تاريخ.
- أقسام منفصلة: حاليًا، القادمة وغير المكتملة، المؤجلة، والمكتملة.
- كل حالة إنجاز مرتبطة بتاريخها للمهام المتكررة.

### المساعد الذكي
- في شاشة المساعد: يبدأ الاستماع من الميكروفون، ويستمر مع إعادة التشغيل بعد السكتات.
- الضغط على زر المربع يوقف التسجيل ويرسل النص مباشرة كما طلب المستخدم.
- رد المساعد يظهر في المحادثة ويُقرأ تلقائياً بالعربية عبر TTS.
- أُضيف زر دائري مموج للمساعد السريع في الشاشات الثانوية فقط: الإعدادات، محرر المهمة، خريطة اليوم والسجل اليومي.
- ضغطة أولى تبدأ الاستماع، وضغطة ثانية توقفه وترسل الكلام وتقرأ الرد دون فتح شاشة جديدة.
- آخر تبادل من المساعد السريع يظهر لاحقاً داخل تبويب المساعد.

### تفاصيل المهمة
- إضافة درجة أهمية: منخفضة، متوسطة، عالية، عاجلة.
- تظهر الأهمية والتصنيف والوصف والمهام الفرعية ضمن بطاقة المهمة الحالية.
- سجل تأجيل مرتبط بتاريخ المهمة.

## البناء والتحقق

1. افتح مجلد `quwat_alaan_final` كمشروع Flutter.
2. شغّل `flutter pub get`.
3. شغّل `flutter analyze` لإظهار أي تحذيرات أو أخطاء بيئية بوضوح.
4. شغّل `flutter build apk --release`.

اسم الحزمة: `com.quwatalan.app2`.

تم فحص توازن الأقواس، وجود الملفات، مراجع الحزم، Manifest، Kotlin وGradle يدوياً وآلياً. لا أستطيع ضمان «صفر أخطاء» قبل تشغيل Flutter SDK الفعلي؛ بيئة العمل الحالية لا تحتوي Flutter SDK أو Gradle Wrapper JAR كامل، لذلك لم أزعم أن APK بُني هنا. لاستخدام حازم قبل البناء، يجب تشغيل `flutter pub get` ثم `flutter analyze` على جهاز البناء، ومعالجة أي رسالة ناتجة عن نسخة Flutter المحلية.
